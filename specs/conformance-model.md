# AEROST Conformance Model

## Classes

- **P** — accept supported programs and reject prohibited or invalid programs with controlled diagnostics.
- **E** — produce normative retained-state, output, diagnostic, and semantic-event traces.
- **B** — generate and separately compile a backend equivalent to AIR execution for controlled traces.
- **A** — produce schema-valid mappings, manifests, hashes, coverage, selected MC/DC, mutation, and traceability records.
- **I** — bind the snapshot, commit, reset, and fault contract to a declared target platform; this class is outside the current host-based research artifact.

A claim-critical mismatch, an open controlled statement/decision/condition obligation, a missing selected MC/DC pair, an unexplained surviving non-equivalent mutant where the relevant suite requires mutation closure, a schema failure, a traceability orphan, or a reproducibility mismatch blocks the associated claim.

The current artifact evaluates Classes P, E, B, and A. It does not claim target-platform conformance under Class I.
