# Multi-Case Assurance Pipeline

The canonical research suite executes every listed application through the same
manifest-driven validation boundary. Each case receives three-path execution,
bounded synthesis, obligation-only reduction, profile-driven mutation-aware
reduction, schema validation, and five-suite comparison.

An authoritative run compiles both generated Rust backends and repeats both case
bundles in clean directories. Aggregate results preserve application identities.
The two-case result demonstrates reuse across two controlled supervisory domains;
it does not establish universal avionics generality or complete vendor independence.
