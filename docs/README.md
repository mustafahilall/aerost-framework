# Technical Documentation

This directory contains concise documentation for the implemented AEROST research system.

- `research-scope.md` — evaluated applications, execution paths, evidence model, scenario provenance, and claim boundaries.
- `evaluation-method.md` — shared two-application evaluation pipeline.

Normative implementation contracts are maintained under `specs/`. Machine-readable schemas are under `schemas/`, and the controlled evaluation evidence is under `artifacts/multi-case/latest/`.
